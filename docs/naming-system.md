# Naming System

Use this language consistently in public copy, navigation, routes, demo content, and docs.

| Product Term | Meaning | Replaces |
| --- | --- | --- |
| Loop | Main community feed and local activity surface | Community Feed |
| Signals | Posts, updates, asks, offers, welcomes, hub updates | Posts |
| Circles | Communities and recurring groups | Groups, generic community |
| Crews | Action teams doing practical work | Teams, action groups |
| Leads | Trusted helpers and community leaders | Mentors, organizers where broader |
| Moves | Events, workshops, drives, meetups, actions | Events |
| Shifts | Work support and fair-work section | Unionized, worker-support labels |

## Signal Types

- Update
- Ask
- Offer
- Welcome
- Move
- Hub Update
- Shift

## Signal Actions

- Boost
- Helpful
- Solidarity
- I can help
- Comment
- Share
