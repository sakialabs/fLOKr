# Roadmap

## MVP Merge

- Rename the main feed surface to Loop.
- Add a Signal composer with type selection.
- Add Signal filters and local reaction affordances.
- Refresh navigation to Home, Reservations, Items, Hubs, Loop, and Settings.
- Keep backend model names stable.

## Next

- Back Signal creation with the API instead of mock/local state.
- Add persisted reactions.
- Add Move detail and join flows.
- Add Shifts as a first-class work-support view or Loop tab.
- Add Circle and Crew membership flows.
- Add Lead discovery and request flows that reuse the existing mentorship foundation.

## Later

- Review whether backend aliases or model renames are worth the migration cost.
- Add map-based Moves where location data is reliable.
- Add moderation and safety tools for Signals, Shifts, and public Moves.
